## Coverage rules (the point of the map)

1. **Single-source dependency audit:** three blocking types currently depend on a single authoritative adapter (taxes→assessor is backed; **lien_status→recorder and flood_zone→FEMA have no second machine source** — by nature: they *are* the authority). Their resilience is therefore the manual path plus adapter-health alerting (RB-03 pages at >20% failure), and this is stated rather than hidden. Occupancy and HOA have **no** machine source at all: their honest ceiling is REPORTED-until-documents, and the UI says so.
2. **Metro expansion gate:** a new metro launches only when every blocking row has its primary adapter live and health-checked there; significant rows may launch on manual-path-only with the coverage map published (`../business/marketing.md` — honest coverage is the brand).
3. **Drill linkage:** RB-03 outage drills rotate through this table's blocking rows quarterly; a drill that finds an undocumented failure path updates this file in the same week.
4. **Cost roll-up check:** the Cost column must reconcile to the evidence-fee line in `../business/financial-model.md` §10 (FY1 $3.10/standard memo across ~11 claims — current roll-up ≈ $3.10 ✓).
5. **Change control:** rows change via PR with Evidence Lead review; a new claim type cannot merge into the taxonomy without its row here (same-PR rule as golden-vector additions).
